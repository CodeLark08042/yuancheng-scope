坐标轴标签密度：三种方案对比

屏幕 480×272，字体 6×8（每字 6px 宽）。波形区 y=22~162（8 格，每格 17.5px），横轴 10 格（每格 48px）。

方案 A每格都标数字（我上一版给的）

问题：文字直接压在栅格里，波形和数字通道都被数字干扰； 10ms 档时底部标签已经开始互相挤压（每格仅 48px，而 10ms 占 24px + 间隔）； 500us 档会出现 1.5ms 这种 5 字符标签，必然重叠。
结论：小屏上信息过载，观感最差。

方案 B真实示波器风格：只给 V/div 和 s/div

优点：最接近真实示波器（Rigol/Tek 都是这个思路）。波形区完全干净，只看格数×量程； 0V 基准箭头和触发点 T 标记是示波器的标准符号，专业感强。
缺点：要自己数格子乘 0.41，对非专业观众不友好；答辩时老师可能问"这个波形多少伏"， 你还要口算。

方案 C稀疏标签：首尾 + 中间各一个（推荐）

含触发电平虚线：颜色跟随触发源通道（此处 CH1 蓝），右侧标 T1.65V。

优点：量程一眼可见（3.3V / 1.6V / 0V，100ms 跨度），文字极稀疏不挡波形； 最左/最右贴边放，波形中间完全干净；比方案 B 更好读，比方案 A 更干净。
触发：触发电平画成虚线横线，颜色跟随触发源（CH1 蓝 / CH2 红）， 右侧标 T1.65V；数字通道作触发源时不画线（协议规定电平对数字触发无效）。
成本：6 个 GUI_DispStringAt + 一条虚线循环 + 每个档位一组字符串常量，约 45 行。

推荐方案 C（稀疏标签），理由：
  • 每个档位只在「首 / 中 / 尾」标 3 个时间值，绝不会重叠，与档位切换天然配合；
  • Y 轴固定 3 个电压值（3.3V / 1.6V / 0V），不随档位变化，代码最简单；
  • 文字全部贴边（x≤2 或 x≥446），不侵入波形区，观感与现在几乎一致；
  • 若之后想更接近真机，在方案 C 基础上再加一个 0V 基准箭头和触发点 T 标记即可（+10 行）。
关于任务书：没有任何一条明确要求坐标轴标签（我核对过 V1.0 全文）。 但「测量电压范围不少于 0~3V」「扫描时间五档可调」这两条隐含了「刻度必须可判读」的意图。 坐标轴属于加分项，不是硬性验收点——时间紧张时可以最后做。
